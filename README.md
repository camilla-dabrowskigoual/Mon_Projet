## 🛠️ Technologies utilisées

## ▶️ Exécuter un exercice

1. Installer Python 3.
2. Télécharger le fichier `.py` souhaité.
3. Ouvrir un terminal dans le dossier du fichier.
4. Lancer la commande :

```bash
python3 nom_du_fichier.py
```

Sous Windows, la commande peut également être :

```bash
py nom_du_fichier.py
```

Remplacer `nom_du_fichier.py` par le nom de l'exercice.
